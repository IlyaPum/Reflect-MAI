# Регламент сбора фотобазы кампуса (этап 2 роадмапа)

Фотобаза — сырьё для офлайн-базы векторов (модуль 1 PRODUCT.md). От её качества напрямую зависит точность фото-засечки (этап 3).

## Цель MVP
- **200–500 фото** территории МАИ с координатами (EXIF).
- Для MVP достаточно **одного сезона**; зимой докатываем (см. открытый вопрос №4 в PRODUCT.md).

## Как снимать (через режим сбора базы в приложении)
1. Включи в приложении **режим сбора базы** (отдельная кнопка в настройках).
2. Встань в точку, с которой видно фасад, **сделай снимок** — GPS и угол компаса автоматически пишутся в EXIF.
3. Один фасад — **снимай с 3–4 разных точек** (слева, справа, прямо, дальше), чтобы фасад распознавался с разных ракурсов.
4. Меняй дистанцию: 20–50 м от здания.

## Что избегать (или снимать компенсирующие кадры)
- ❌ Машины, люди, деревья на переднем плане, закрывающие фасад.
- ❌ Кадры с большим количеством неба (более 50 %).
- ⚠️ Один и тот же фасад в разное время суток и при разной погоде — плюс, а не минус.

## Что должно войти в базу
- Все учебные корпуса (1–8) с разных сторон.
- Главные ориентиры: столовая, входы, крупные отличающиеся здания.
- Дорожные точки, с которых студент реально делает засечку (по сценариям B/C).

## После съёмки
1. Выгрузить фото в `dataset/raw/` (в git **не коммитить** — см. `.gitignore`, фото живут в облаке/LFS).
2. Прогнать через утилиту `tools/` (будет написана на этапе 3): фото → векторы → `assets/db/landmarks.bin`.
3. Проверить в тестах: top-1 точность распознавания ≥ 80 % (критерий этапа 3).

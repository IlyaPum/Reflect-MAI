# Reflect

Автономный офлайн-навигатор по кампусу МАИ для студентов: определяет местоположение **без GPS и интернета** — по фотографии здания (visual place recognition) и датчикам движения телефона (шагомер + компас) — и ведёт пользователя до нужного корпуса.

## Как это работает

1. **Засечка по фото** — пользователь снимает ближайшее здание, нейросеть узнаёт фасад и ставит точку на карте.
2. **Ведение по шагам** — позиция двигается в реальном времени за счёт шагомера и компаса, даже когда телефон в кармане.
3. **«Веди меня до корпуса N»** — приложение строит пешеходный маршрут по территории кампуса и ведёт по нему стрелкой.
4. **Уточнение** — при накоплении погрешности (50–150 м) приложение просит сфотографировать следующее здание и сбрасывает ошибку.

Всё работает локально: один APK (~40–60 МБ), ни одного запроса в сеть.

## Стек

- **Flutter (Dart)** — приложение
- **flutter_map** + растровые тайлы OSM — офлайн-карта
- **tflite_flutter / onnxruntime_flutter** — лёгкая CNN-эмбеддер на устройстве
- **sensors_plus + flutter_compass** — шагомер, азимут
- **camera + native_exif** — съёмка и запись координат при сборе базы
